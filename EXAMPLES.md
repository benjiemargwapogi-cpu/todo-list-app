# Example Usage Scenarios

## Scenario 1: Personal Task Management

### Situation
You want to organize personal tasks: fitness, home maintenance, learning, shopping.

### Setup
1. Categories: Personal, Health, Learning, Shopping, Home
2. Priority levels: High (urgent), Medium (this week), Low (when I get to it)

### Workflow
```
Sunday Evening - Planning:
  ➕ Add: "Grocery shopping" (Medium, Due: Tuesday, Shopping)
  ➕ Add: "5-mile run" (High, Due: Monday, Health)
  ➕ Add: "Fix leaky kitchen faucet" (Low, Due: Next weekend, Home)
  ➕ Add: "Python course lesson 5" (Medium, Due: Friday, Learning)
  
  Dashboard shows: 4 total, 0 completed, 2 high priority

Monday:
  ✅ Mark Complete: Task ID 2 ("5-mile run")
  Dashboard: 4 total, 1 completed, 25% done

Tuesday:
  ✅ Mark Complete: Task ID 1 ("Grocery shopping")
  Dashboard: 4 total, 2 completed, 50% done
  📊 Sort by Priority: High priority task (if any) moves to top

Friday:
  ✅ Mark Complete: Task ID 4 ("Python course")
  Dashboard: 4 total, 3 completed, 75% done

Weekend:
  ✅ Mark Complete: Task ID 3 ("Fix faucet")
  Dashboard: 4 total, 4 completed, 100% done! 🎉
  🧹 Clear All: Start fresh for next week
```

## Tips for Each Scenario

### Personal Tasks
- Use broad categories
- Mix high and low priority
- Daily review of dashboard
- Weekly clear-all for fresh start

### Work Projects
- Use specific categories for teams
- High priority for blockers
- Due dates tied to deadlines
- Regular export to PDF for reports

### Events
- Plan backwards from event date
- Use realistic time estimates
- Update as RSVP status changes
- Export final checklist

### Renovations
- Track by phase
- High priority for critical path
- Add tasks as you discover needs
- Keep for resale records

### School
- Add all assignments from syllabus
- Sort by due date early in semester
- Review dashboard weekly
- Export as semester record

### Sales
- Use categories matching sales pipeline
- Daily or weekly reviews
- Export for management reports
- Clear weekly and restart
